# Vanitas Studios — Full Stack Ecosystem

**Vanitas** non è solo un progetto, ma un simbolo di sintesi tra visione creativa e ingegneria software rigorosa. Questo repository ospita l'infrastruttura Full Stack del portale, progettata per essere il ponte tra un world-building immersivo e un'architettura tecnica robusta e scalabile.

## 🏛 Architettura Tecnica

Il sistema è stato sviluppato con una mentalità orientata alle performance e alla sicurezza, coprendo l'intero ciclo di vita del dato:

* **Backend & Security:** Core logico sviluppato in **C#**, utilizzando **Entity Framework** per l'orchestrazione dei dati e **ASP.NET Core Identity** per la gestione avanzata della sicurezza e dell'autenticazione utenti.
* **Database:** Progettazione e gestione di schemi relazionali complessi in **SQL**, ottimizzati per garantire integrità e velocità di risposta.
* **Frontend:** Interfaccia custom ad alto impatto estetico realizzata interamente in **Vanilla JavaScript (ES6+)**, **HTML5** e **CSS3**. La scelta di evitare framework pesanti riflette la volontà di mantenere il pieno controllo sul rendering, sulle performance e sull'esperienza utente (bespoke UI/UX).
* **Game Logic Integration:** Sincronizzazione fluida tra le logiche di gioco e l'infrastruttura web, garantendo coerenza tra l'ambiente di sviluppo indie e il portale digitale.
